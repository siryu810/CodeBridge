## 撮影内容

### home.png

ホーム画面全体。次が見える状態:

- 学習進捗（達成率など）
- 「次に学ぶ」カード
- 学習ロードマップの一部
- おすすめ／サンプルへの導線

### editor-jp-to-c.png

IDE 画面。「日本語 → C言語」モード。

- 左: 日本語コード（Monaco）
- 右: C言語変換結果
- 下: コンソール（実行後の出力があると望ましい）

### practice-mode.png

サンプルを開き、練習パネルを表示した状態。

- 問題文
- ヒント（1つ以上表示してもよい）
- コード入力欄
- 提出・採点結果（成功またはヒント付き失敗）

### code-compare.png

「参考コードとの違い」モーダル（またはパネル）を開いた状態。

- 自分のコードと参考コードの差分が分かる
- 日本語どうし、または C どうしの比較
- 採点基準ではなく学習用であることに注意

### learning-roadmap.png

ホームの学習ロードマップ周辺。

- 第○章の一覧
- 進捗バー
- クリア／ロック状態が分かる

### demo.gif

5〜15 秒程度。おすすめ流れ:

1. 日本語で書いて変換結果が出る
2. 実行してコンソールに出る
3. 練習をクリアする（任意）
