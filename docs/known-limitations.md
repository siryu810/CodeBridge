# CodeBridge 既知の制限

U-22 提出版（`0.9.0-rc.1`）時点で把握している制限です。実装と矛盾する場合はコードを優先します。

---

## エディタ（Monaco）

- **Monaco の JS チャンクが大きい**（本番ビルドで数 MB 規模）。オフライン動作のためにローカル同梱しているためです。
- **初回ロードに時間がかかる**可能性があります（特に本番ビルド初回）。
- Monaco 初期化に失敗した場合は **textarea フォールバック**に切り替わります（編集・コピーは可能、ハイライト等は不可）。

## 実行環境

- **C コードのコンパイル・実行**には、ローカルの Express（`npm start` / `npm run dev`）と **gcc** が必要です。
- インターネット Offline でも、**ローカルサーバーが起動していれば**実行できます。
- インターネット Offline と「実行サーバー未起動」は別問題です。後者では変換・編集はできても実行は失敗します。

## 変換エンジン

- **完全な C 言語構文解析ではありません。** 学習向けの対応範囲に限定しています。
- **日本語 ↔ C 変換**は対応辞書・構文ルールの範囲内です。未対応構文は変換できない／警告が出ることがあります。

## 学習データ・進捗

- 学習進捗・ロードマップ設定は **ブラウザの localStorage** に保存されます。
- **端末・ブラウザをまたいだ同期はありません。** 別 PC やシークレットウィンドウでは進捗が共有されません。
- キャッシュ削除やサイトデータの消去で進捗が消えます。

## ドキュメント・資産

- **`docs/images/` の実画像**（home.png 等）は配置ガイドのみ用意しており、未配置の場合があります。撮影手順は [images/README.md](images/README.md) を参照してください。

## オフライン

- インターネット接続は不要でも、**UI 表示にはビルド成果物／開発サーバー**、**実行にはローカル Express + gcc** が必要です。
- 手順は [offline-test.md](offline-test.md) を参照してください。
