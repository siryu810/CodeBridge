# CodeBridge デモ手順（約 5 分）

発表・審査向けの操作ガイドです。各ステップは **30 秒程度** を目安に進めてください。

事前準備：`npm run dev` を起動し、http://localhost:5173 を開いておく。gcc が PATH にあることを確認する。

---

## ① CodeBridge 紹介（30 秒）

**見せる画面：** ホーム

**話すこと：**

- CodeBridge は「日本語で C 言語を学ぶ学習 IDE」
- 翻訳ツールではなく、**考え方を学ぶ環境**
- サンプル 24 件・練習・進捗・ロードマップで初学者を支援

**操作：** ホームを上から少しスクロールし、進捗サマリーとロードマップを見せる。

---

## ② 日本語 → C 言語（30 秒）

**見せる画面：** サンプル「こんにちは」または新規作成

**操作：**

1. ホームから「Hello, World」系サンプルを開く
2. モードが「日本語 → C 言語」であることを確認
3. 左のエディタに `表示("こんにちは");` があることを見せる
4. 右の「変換結果」パネルに `printf` が出ることを見せる

**話すこと：** 英語の記号に触れる前に、日本語でアルゴリズムの流れを書ける。

---

## ③ C 言語 → 日本語（30 秒）

**操作：**

1. ツールバーで「C 言語 → 日本語」に切り替え
2. エディタに C コード（`printf` / `if`）が表示される
3. 変換結果に日本語（`表示` / `もし`）が出ることを見せる

**話すこと：** 授業や AI が出した C コードを、日本語で読み解ける。

---

## ④ 実行（30 秒）

**操作：**

1. 「日本語 → C 言語」に戻す
2. 入力が必要なサンプル（例：入力エコー）を開く
3. 下部の「実行時入力」に値を入れる
4. 「▶ 実行」を押し、コンソールに結果が出ることを見せる

**話すこと：** ブラウザから gcc でコンパイル・実行。エラーは日本語で表示される。

---

## ⑤ 学習モード（30 秒）

**操作：**

1. 右端レールの「学習」をクリック
2. アルゴリズムのステップ（①②③…）を見せる
3. 命令をクリックすると辞書モーダルが開く（任意）

**話すこと：** コードの「流れ」をステップで追える。

---

## ⑥ 練習モード（30 秒）

**操作：**

1. レールの「練習」を開く（またはツールバーの「練習」）
2. 問題文とヒントを見せる
3. エディタで回答を書き、「提出して採点」→ 採点結果と解説を見せる

**話すこと：** 各サンプルに練習が付いていて、クリアすると進捗に記録される。

---

## ⑦ コード比較（30 秒）

**操作：**

1. 練習で意図的に少し違うコードを書く、または不正解にする
2. 「参考コードとの違い」を押す
3. 差分（追加・削除・変更）とヒントを見せる

**話すこと：** 正しく動けば書き方は人それぞれ。参考コードとの違いを学習用に確認できる。

---

## ⑧ 学習進捗（30 秒）

**操作：**

1. 「← ホーム」で戻る
2. 進捗サマリー（達成率・クリア数）を見せる
3. カテゴリ別進捗バーを見せる
4. サンプルカードの ✓ マークを指す

**話すこと：** localStorage に保存され、続きから学習できる。

---

## ⑨ ロードマップ（30 秒）

**操作：**

1. 「学習ロードマップ」までスクロール
2. 第 1 章のみ開放・章ごとの進捗バーを見せる
3. 「次に学ぶ」カードを見せ、開始ボタンで次の章へ誘導されることを説明

**話すこと：** 「何を学べばいいか分からない」問題を、9 章のコースで解決する。

## トラブル時のフォールバック

| 状況 | 対処 |
|------|------|
| gcc 未検出 | 変換・学習・練習はデモ可能。実行だけスキップし、変換結果を見せる |
| 実行サーバー未接続 | 画面上部のステータスを確認。`npm run dev` を再起動 |
| 練習が正解にならない | 模範に近い行構成にするか、「比較」で差分を見せるデモに切り替え |

## おすすめデモ用サンプル

| 順番 | サンプル | 理由 |
|------|----------|------|
| 入門 | hello | 変換が一目で分かる |
| 実行 | input-echo | 入力と出力が短い |
| 練習 | even-odd | 条件分岐の練習が分かりやすい |
