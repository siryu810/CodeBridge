# Practice Focus Layout Report

## 見ないで挑戦時のレイアウト

- IDE 中央（日本語コード / C言語変換 / Bottom Panel）を畳み、練習ホストをメイン領域へ拡大
- 練習画面の構成:
  - 上部: モード切替・問題文・ヒント・「参考コードを見る」
  - 中央: 自分のコードエディタ（拡大）
  - 下部: 入力・実行・提出・採点結果・実行ログ
- 見ながら練習は従来どおり右スライドの練習パネル + IDE 構成を維持
- Bottom Panel との重複回避: 見ないで挑戦中は IDE 下部パネルを非表示。実行・入力は練習画面側のみ

## 参考コードの表示方法

- ページ遷移なし
- `PracticeReferenceDrawer` で表示
  - 通常幅: 右側スライドドロワー
  - 狭い画面（〜900px）: 下ドロワー
- 見出し「参考コード」・閉じる・コピー（クリップボードのみ、回答欄へは自動反映しない）
- 自分のコードと同時に閲覧可能（エディタはアンマウントしない）

## レスポンシブ動作

- ≤900px: 参考コードは下ドロワー、練習フォーカスはレール左の全域
- ≤480px: 練習ホストをフル幅寄りに拡大
- 右ドロワー幅は最大でも画面の約半分に制限し、エディタが極端に狭くならないようにした

## 状態保持

- 練習パネルは `practice-host` に常駐（サンプル中）し、モード切替でもインスタンスを維持
- 参考コードの開閉では回答コード・入力・実行/採点結果・ヒント状態を保持（エディタも維持）
- 見ながら ⇄ 見ないで: 回答・入力・結果を維持。Bottom Panel の開閉は復帰時に復元
- 問題切替時のみ従来どおりリセット（見ながら練習へ）

- 見ないで挑戦中はツールバーの「実行」「変換結果」を隠す（練習内の実行を使う）
- 学習・対応表・エラーの右パネルは従来どおり利用可能
